# Project map -- __GAME_NAME__

This map says **where** each thing is. For the rest: `docs/GDD.md` (**why** the game is tuned this
way) - `docs/PITFALLS_UNITY.md` (index of the **pitfalls**, open the domain) - `CLAUDE.md` (current
phase and conventions).

> **Keep this map up to date**: as soon as you add, remove or rename a system, a screen, a piece of
> data or a tool, update the relevant section **in the same commit**. A stale map is worse than no
> map -- it gives a wrong answer with authority. When in doubt, check the file before asserting it;
> do not copy blindly.

> WARNING: **ceiling: ~150 lines.** This map is loaded in full at every invocation, and it grows
> with the project -- measured at 12 KB on a small game, that is 3,000 tokens reloaded every time
> someone looks for a file. It says **where**, in one line per entry. The *how* belongs to the code,
> the *why* to the GDD. Beyond the ceiling, move the checklists out to a neighbouring file rather
> than making this one longer.

## sec. Tools -- `tools/`

| Tool | What it does |
|---|---|
| `build.ps1` | **Builds** (Windows/web), and `-Run` chains on to the capture. The only caller of Unity |
| `configure.ps1` | Says where Unity, Python, dotnet and butler are -- and what is missing |
| `environment.ps1` | Resolves and remembers those paths (`local.settings.json`, out of git). Dot-source it |
| `release_itch.ps1` | Publishes a version (build -> butler push -> commit). `/publish-itch` skill |
| `serve_web.py` | Serves `Build/Web` **without browser cache** -- indispensable after a rebuild |
| `drive_game.py` | Launches the Windows build, injects keys, captures the window |

WARNING: **no external tool path hard-coded anywhere**: `Unity.exe` is not in the same place from
one machine to the next. Everything goes through `environment.ps1`.

## Wiring checklists

Content added "halfway" raises no error: it is simply inert. Keep here the list of points to touch
for each type of addition.

**Adding a piece of content** (example to adapt):
1. The data (JSON / ScriptableObject).
2. The matching rule in `Rules/` **and its test**.
3. The engine wiring (`Gameplay/`).
4. The **sound** -- WARNING: an entry missing from the audio table is silent, with no error.
5. The **sprite** -- WARNING: check `Resources/` vs `Art/`, getting it wrong shows nothing abnormal.
6. The **text** (name, description) and its localisation key.
7. Updating this map, in the same commit.
