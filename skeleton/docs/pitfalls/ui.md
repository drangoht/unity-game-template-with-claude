# Pitfalls -- Interface


**WARNING: the HUD can cover a modal.** The canvas sorting order is the only arbiter: two canvases
with the same `sortingOrder` stack in hierarchy order, which is not stable when the scene is
regenerated by code. Give every canvas an explicit `sortingOrder`.

**WARNING: a focus trap is only visible with a gamepad.** A list whose focus can no longer get out
navigates perfectly with the mouse. Test every screen **with the keyboard and with a gamepad**.

**WARNING: invisible reads as non-existent.** [inherited] An ability that does not announce its key
does not exist for the player: on a previous project, a dash was played for a whole session without
the tester knowing a key existed. A passive effect with no indicator is believed to be inactive. That
is an ergonomics bug, not a presentation detail.
