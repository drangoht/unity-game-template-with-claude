## Conventions

- **Build**: `& "tools/build.ps1"` -> `Build\Windows\__NAMESPACE__.exe`; `-Target web` ->
  `Build\Web\`; `-Run` chains launch and capture. WARNING: the Unity editor must be **closed**.
- **Publishing**: `tools/release_itch.ps1 -Version X.Y.Z` (try `-DryRun` first). The script sets
  `bundleVersion` itself -- **do not edit it by hand**.
- **The scene is an ARTEFACT**: `Assets/Scenes/Game.unity` is regenerated by `SceneBuilder.Build()`
  at every build. You add an object to the game **by writing code**, not by clicking in the editor.
  It comes out modified after every build -- discard it (`git checkout --`) unless `SceneBuilder.cs`
  has changed.
- **Pure testable logic**: `Assets/Scripts/Rules/` -- static classes **with no engine dependency**.
  The `MonoBehaviour`s delegate to them. Tests: `dotnet test tests/__NAMESPACE__.Tests.csproj` (no
  engine, no build required; replayed by a hook after every edit).
- **Nothing deprecated**: URP (never Built-in), Input System (never the old Input Manager). Report
  any deprecation warning without waiting to be asked.
- **No hard-coded tool path** (Unity, Python): `tools/environment.ps1` resolves them and remembers
  them in `tools/local.settings.json`, not versioned.
- Style: PascalCase for classes/methods, `_camelCase` for private fields, `readonly` by default.
  Comments in English, and they explain the **why**.
- Tuning must be adjustable **without recompiling** as soon as a value deserves to be tried several
  times.
- UI palette: <!-- hex codes --> - Font: <!-- family -->
- WARNING: three pitfalls that raise nothing and are met everywhere -- the detail in the file named:
  **AZERTY** keyboard (`docs/pitfalls/input.md`), `Art/` is not `Resources/`
  (`docs/pitfalls/assets-import.md`), misleading Unity exit code (`docs/pitfalls/build.md`).

## Doc maintenance

- Update **in the commit** that makes what they describe wrong: `docs/gdd/`, `/project-map`,
  `docs/pitfalls/`. A stale document gives a wrong answer with authority.
- `README.md` -- update at every phase change or major addition.
- WARNING: **every document re-read at every task has a ceiling** (this file: 80 lines; `GDD.md`,
  `/project-map`: 150; a pitfalls or system file: 150). Once reached, **split** and leave an index.
  Without that reflex, the cost per task climbs until it exceeds the task.
